## 1. surfcore（DSH 插件：QQ / B站 / 桌宠）

```
地址    https://github.com/Mieksido/surfcore
版本    0.8.9
许可    MIT（SnowLuma 是第三方专有运行时，不随仓库分发）
用途    给 DSH 一个 QQ 身份：通过 SnowLuma 接入 QQ，附带 B站工具与桌宠
安装    npm install → node scripts/setup-dsh.mjs → 重启 DSH → 设置 → 诊断 → 一键安装
前置    DSH ≥ 0.2.1-rc.2（本机 0.2.1-rc.5 通过）
```

**踩过的坑（2026-11-22）**

```
① setup-dsh.mjs 报 "insert must be an array"
   原因：~/.dsh/profiles/desktop/cordis.patch.yml 尾部有一段残缺的 `- insert:`
   处理：删掉那段残缺块再重跑

② dsh plugin install 退出码 1
   原因：profile 里另一个依赖 dsh-memewiki 拉 GitHub release 超时
   处理：给 pnpm 挂代理（HTTPS_PROXY）后才装完
```

**现状**：已安装（bundle link + profile 依赖 + 3 个 MCP server 写入 patch）。
未走「设置 → 诊断 → 一键安装」，因为那一步会把 QQ 从 AstrBot 切到 DSH——尚未切换。

## 2. dsh-compat-astrbot（在 DSH 里跑 AstrBot 插件）

```
地址    https://github.com/shingflash/dsh-compat-astrbot
用途    伪造 astrbot 包，让 AstrBot 插件在 Node/DSH 里加载
结论    只伪造 4 个接口（register / command / llm_tool / on_llm_request）
        我们的插件多数挂在 on_llm_response 上 → 探测阶段即失败，不可用
实测    private_only / poke_reply / llm_cost 三个全挂
```

## 3. astrbot_plugin_compat_dsh（在 AstrBot 里跑 DSH 插件）

```
地址    https://github.com/shingflash/astrbot_plugin_compat_dsh
版本    1.0.2
许可    MIT
用途    每个 DSH 插件起一个 node 子进程跑 host/boot.mjs，
        劫持 cordis / @deepseek-ai/dsh-tools 的 import，把工具与提示词转给 AstrBot
接入    放 data/plugins/，plugin_dirs 填 DSH 插件目录（; 分隔）
```

**实测能通的 DSH 插件**

```
dsh-memewiki         ✅  2 个工具 + 1 个 prompt hook
dsh-bili-humanism    ❌  ctx.tools.guard is not a function（shim 没实现）
dsh-context          ❌  Cannot find package '@deepseek-ai/dsh-session'（只替了两个包）
```

**我们打的补丁**：`参照/patches/compat_dsh-20261123.patch`

```
① _make_handler 的参数签名
   async def handler(**kwargs) → (*args, **kwargs)
   AstrBot 按 (event, **kwargs) 调用，原写法报
   "takes 0 positional arguments but 1 was given"

② start() 里读管道顺序
   原来先起 _read_loop 再自己 readline 等 ready 帧，两个协程抢读同一根 stdout，
   回复帧会被错分走 → 工具调用永远等不到结果，120 秒超时
   改成：先读 ready 帧，读完再启动读循环
```

修完实测：`search_meme_wiki` **29 毫秒**返回结果（原来是 120 秒超时）。

## 4. 素体（阿暖出品，单进程 Node 聊天程序）

```
来源    别人发来的 zip（0.5 MB），非 GitHub 仓库
许可    代码 MIT、文档 CC BY 4.0；再分发必须保留 LICENSE 与「阿暖出品」署名
规模    45 个文件 / 1.4 MB 源码 / bot.js 14,004 行
用途    只作架构参照，未安装、未运行
```

**值得借鉴的三处**

```
① 工具三层收口    tools-registry（清单）→ tool-router（路由）→ tool-gate（闸门，risk 0/1/2）
② 契约分三层      always（漏一次就是事故）/ when（按信号触发）/ 其余按需
                  防漏网：同一条 when 契约连续 N 次没被触发，强制带一次
③ 性格影子模式    六轴只算不注，先攒数据再校准
```
