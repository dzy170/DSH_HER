## 反过来：astrbot_plugin_compat_dsh（DSH 插件进 AstrBot）

装进 `data/plugins/`，`plugin_dirs` 指到 `dsh-memewiki`。

```
注册成功    memewiki__search_meme_wiki / feedback_meme_wiki（2 个工具 + 1 个 prompt hook）
实测        第一次调用 TypeError；修完签名后 120 秒超时；再修读管道顺序后 29 毫秒返回
```

**我们改了两处** → `参照/patches/compat_dsh-20261123.patch`

```
① async def handler(**kwargs) → (*args, **kwargs)      （AstrBot 按 (event, **kwargs) 调用）
② start() 里先读 ready 帧、再起读循环                    （原来两个协程抢读同一根 stdout）
```

## 顺手加的度量（llm_cost 插件）

```
sections       system 里每个【…】小节各占多少字
registered     全局工具表注册了哪些工具
full_set       人格合并那步能看到的工具集
tools          这次请求实际带了哪些工具
tool-calls.jsonl   真调用时单独记一行：时间 / 会话 / 工具名 / 参数 / 她那句原话
```

加这些的原因：今天为了判断"她为什么不用工具"，先后误判了三次——
先说"没注册"、再说"没送进请求"，最后才发现工具一直在，是**调用时崩了**。
没有这几列，只能靠猜。
