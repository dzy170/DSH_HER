# DSH_HER

给「大肥鱼」这套系统做参照用的仓库：**只放上游仓库的清单、我们对第三方的补丁、每天改了什么。**

不放运行数据（人格、日志、聊天记录、备份），不放第三方仓库的整份代码。

## 这里有什么

```
参照/清单.md            我在用的上游仓库：地址、版本、用它哪一部分、为什么用它
参照/patches/           我们对第三方做的改动（unified diff，可直接 git apply）
日志/YYYY-MM-DD.md      当天改了什么、为什么改、怎么验证的
```

## 怎么用这些补丁

```bash
# 先把上游仓库 clone 到本地，按清单里写的 tag/commit 切过去
git clone <upstream> && cd <upstream>
git checkout <tag>
git apply /path/to/DSH_HER/参照/patches/<名字>.patch
```

补丁头部用的是 `a/<仓库内相对路径>`，所以在仓库根目录执行 `git apply -p1` 即可。

## 为什么要单独记这一份

上游仓库会更新、会被删、作者会改主意。**这份仓库记的是"我当时用的是哪一版、我改了什么"**——
换机器、重装、或者哪天上游把它删了，照这个清单能复原。
